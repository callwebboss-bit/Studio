# Yakir Cohen Studio

ברוכים הבאים למאגר הרשמי של **Yakir Cohen Studio**.

מאגר זה משמש לאחסון קבצי האתר, דפי HTML, עיצובים, תוספים, ותוכן נוסף הקשור לפיתוח האתר והמערכת של יקיר כהן הפקות.

---

## 📁 מבנה הפרויקט

המאגר כולל:

- **index.html** — עמוד הבית של האתר (חובה עבור GitHub Pages)
- **עמודי HTML נוספים** — כמו about.html, contact.html, order.html ועוד
- **תיקיות סטטיות**:
  - `/css` — קבצי עיצוב
  - `/js` — קבצי JavaScript
  - `/images` — תמונות וגרפיקה
  - תיקיות נוספות לפי הצורך

---

## 🌐 פריסת האתר (GitHub Pages)

האתר מתפרסם אוטומטית באמצעות GitHub Pages.

כדי להפעיל את האתר:

1. היכנס ל־**Settings**
2. עבור ל־**Pages**
3. בחר:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
4. שמור
